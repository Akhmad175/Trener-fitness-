# Фитнес-тренер для Claude

Агент-тренер лежит в `.claude/agents/trainer.md`.

Как пользоваться: в приложении Claude откройте раздел **Code**, создайте сессию с этим репозиторием и напишите: «Позови trainer, хочу начать худеть».

## Приложение «Минус»

Личный дневник похудения: калории и БЖУ, вода, вес, тренировки, шаги и статистика.
Файлы: `index.html`, `manifest.json`, `sw.js`, `icons/`. Без сервера и регистрации: данные хранятся в `localStorage` браузера.
Резервная копия: «Профиль» → «Скачать копию» / «Загрузить из файла».
После изменения `index.html` увеличьте `VERSION` в `sw.js`, чтобы телефон получил новую версию.
